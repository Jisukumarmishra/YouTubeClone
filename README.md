# YouTubeClone

A front-end clone of YouTube's user interface built using **HTML** and **CSS**.

## About

This project is a static UI clone of YouTube. It recreates the look and feel of YouTube's homepage and layout using only HTML and CSS, including features like the navigation bar, video grid, and sidebar.

## Technologies Used

- HTML
- CSS (Flexbox & Grid)

## Files

- `youtube.html` – Main YouTube clone page
- `flexbox.html` – Layout experiments using CSS Flexbox
- `grid.html` – Layout experiments using CSS Grid
- `position.html` – Layout experiments using CSS Positioning
